# 🇮🇳 Indian Startup Funding Analysis

## 📊 Project Overview

This project analyzes the **Indian Startup Funding ecosystem** to understand funding patterns across startups, investors, sectors, cities, and funding-related categories.

The project follows a practical **Data Analyst workflow**, starting with dataset exploration and analysis and then presenting the findings through an interactive **Power BI dashboard**.

The main objective is to transform raw startup funding data into meaningful business insights that can help understand investment trends and the Indian startup ecosystem.

---

## 🎯 Objectives

The project aims to answer important business questions such as:

* How many startups are present in the dataset?
* How many funding deals were recorded?
* Which sectors receive the most funding?
* Which cities have the highest startup funding activity?
* Which investors participate in the most deals?
* What are the major funding patterns?
* How does startup funding vary across different categories?
* Which startups and investors stand out in the dataset?

---

## 🗂️ Dataset

The project uses an **Indian Startup Funding dataset** containing information related to startup funding deals.

The dataset includes information such as:

* Startup / Company Name
* Funding Amount
* Funding Type
* Sector / Industry
* City / Location
* Lead Investor
* Other funding-related attributes

The raw dataset is available in the repository as:

`Indian_Startup_Funding_Dataset.csv`

## 🔍 Data Analysis Process

The project follows these main steps:

### 1. Data Exploration

The dataset was first explored to understand:

* Number of rows and columns
* Column names
* Data types
* Unique values
* Category distributions
* Missing values
* Basic statistics

### 2. Data Preparation

The dataset was reviewed and prepared for analysis by checking:

* Missing values
* Duplicate records
* Inconsistent categories
* Data types
* Categorical values
* Funding-related fields

### 3. Exploratory Data Analysis

Different aspects of the startup funding ecosystem were analyzed, including:

* Startup funding activity
* Sector-wise distribution
* Investor activity
* Funding types
* Geographic distribution
* Overall funding patterns

### 4. Power BI Dashboard

The prepared data was imported into Power BI to create an interactive dashboard.

The dashboard includes:

* KPI cards
* Funding analysis
* Startup analysis
* Investor analysis
* Interactive charts
* Slicers for filtering the data
* Geographic visualization
